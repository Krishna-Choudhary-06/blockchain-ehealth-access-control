# Blockchain E-Health Access Control

Implementation of the paper:
"An Adaptive Blockchain-Enabled Access Control Framework 
for Secure and Privacy-Preserving E-Health Data Sharing"
by Notash, Jamali, Fotohi (2026)

## Tech Stack
- Hyperledger Fabric 2.5
- Node.js 18
- IPFS
- AES-256 Encryption

## Project Structure
- chaincode/     → Smart contracts (4 phases of paper)
- app/           → Backend API
- frontend/      → Demo UI
- docs/          → Weekly reports and diagrams
